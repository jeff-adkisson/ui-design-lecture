# Handout: AI Slop vs. Agentic Software Engineering

A two-sided, two-column printed handout for the lecture. The left column shows how AI slop gets
made; the right column shows the disciplined human-plus-agent alternative: design, living
architecture docs, iteration, automated testing, standards, code review, adversarial review by an
agent from a different lab, and review-ready code submissions.

| File | What it is |
|---|---|
| `AI-Slop-vs-Agentic-SWE.docx` | The handout. US Letter, print double-sided, flip on long edge. |
| `AI-Slop-vs-Agentic-SWE.pdf` | A rendered copy for quick printing. |
| `build.js` | Generates the `.docx`. All text lives in plain arrays near the top. |

Rebuild after editing: `node build.js AI-Slop-vs-Agentic-SWE.docx` (needs the `docx` npm package).
