Hover rail: resting the pointer on any block shows a vertical rail just outside the block's left edge. It follows the pointer inside tall blocks and never leaves the visible area. Buttons: thumbs, stars, markers, note.
- Thumbs, stars, and markers open a flyout on hover. The user must click a value; the main icon sets nothing. Clicking the main icon clears that family's stamp if the block has one.
- Thumbs: up, down. Stars: 1 to 5. Markers: question mark (follow up), flag, bomb (deal breaker), fire (strong), clapping hands (great answer).
- One stamp per family per block per user. A new value replaces; the same value removes.
- Note opens a small editor under the block with focus in the text box. Enter saves, Escape cancels.
- Stamps never open an editor. Text is added by clicking the stamp's chip or its panel row.

Margin chips: every note is a chip in the right margin aligned to its block, icon only until hovered. Click opens a card to edit text, change the value, or delete.

Notes panel: notes in report order grouped by page and section heading. Clicking a row switches page, scrolls, flashes the anchor, and opens a collapsed section if needed.

Durability: each note stores section heading, quoted text, type, value, author, time, and report version. Reports change rarely; a note whose text can no longer be found goes to an Unplaced group at the top of the panel instead of being lost.
