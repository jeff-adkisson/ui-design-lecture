# Lecture prompts

Paste these into one agent session, in order. Prompt 0 runs before the lecture; its output is already
in `finished-design/pass-4/`. Each prompt ends with a "Lecture time limits" trailer that keeps the
live demo short; a real run would leave it out. `slide-summaries.md` paraphrases prompts 1 to 6.
